### About

Computer engineer working on **SIEM engineering and detection** for MDR/SOC services in banking and critical-infrastructure environments.

- **Detection engineering** in Microsoft Sentinel (KQL): 50+ analytics rules and use cases designed or tuned, ~20% fewer false positives.
- **Telemetry onboarding**: Linux forwarders, syslog, Azure Monitor Agent, third-party sources such as Akamai.
- **Incident response**: phishing and identity incidents with Defender XDR and Entra ID; 16,000+ alerts triaged in an international banking SOC.
- **Automation & AI for the SOC**: Sentinel automation rules, Python tooling, and evaluating where LLMs help analysts and where they need human oversight.
- An attacker's view helps me write better detections: 9 accepted vulnerabilities in public bug bounty programs (HackerOne, YesWeHack).
